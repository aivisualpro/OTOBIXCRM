# Otobix CRM

Otobix CRM is a real-time, high-performance customer relationship management platform tailored for the automotive auction industry. Built on Nuxt 3, Vue 3, and Tailwind CSS.

## Features
- **Real-Time Synchronisation:** Server-Sent Events (SSE) keep clients updated instantly across retail, sales, and lead management.
- **Role-Based Access Control (RBAC):** Sandboxed workspaces and strict permission scoping ensures isolated data views.
- **Performance Optimized:** SWR-style data layer combined with caching prevents unnecessary layout thrashing.
- **Modern Tech Stack:** Nuxt 4 RC (Vite & Vue 3.5), Shadcn Vue, Tailwind CSS, MongoDB natively.

## Setup
```bash
# Install dependencies
pnpm install

# Run the dev server
pnpm dev
```
