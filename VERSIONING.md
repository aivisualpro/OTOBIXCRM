# Versioning Guidelines

**Important:** We are currently using a manual versioning system. 

Whenever you make any changes to the codebase, you **must** update the version number.

### How to Update the Version

1. Locate the `app/components/layout/SidebarNavFooter.vue` file.
2. Find the version string near the `<template>` tag. It looks like `version b.X.XX`.
3. Increment the version number by **`+0.01`**.

**Example:**
If the current version is `b.0.91` and you make a change, update it to `b.0.92`.

---
*Note: This process ensures that everyone knows the latest deployed codebase version at a glance from the bottom-left sidebar.*
